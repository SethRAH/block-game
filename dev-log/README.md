# Dev-log

A short, dated record of what the team built and why, one entry per milestone.

- **File name:** `YYYY-MM-DD-short-slug.md` (the date the milestone shipped).
- **Contents:** what changed, the decisions behind it, how it was checked, and
  what's next. Keep it factual and skimmable; link PRs and commits.
- **Source of truth:** take facts from git history and the PRs, not from memory.
- Entries are append-only. If something turns out wrong, add a correction in a
  newer entry instead of rewriting history.
